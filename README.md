# skills

Agent skills.

- [herdr-orchestrate](herdr-orchestrate/) — simple orchestration, not a DAG. Named profiles route an orchestrator and workers.
- [agent-kanban](agent-kanban/) — a read-only web board for following agent-owned tasks, assignments, review and progress.
- [diagram-walkthrough](diagram-walkthrough/) — "show me how this works" as a stepped reladraw diagram, with overlays for the concepts that aren't boxes.
- [small-blocks](small-blocks/) — plan a task into small blocks, then implement, verify, stage and pause for Hunk review one block at a time.
- [do-this](do-this/) — lead replies with a short "Do this" table of the user's next actions.
